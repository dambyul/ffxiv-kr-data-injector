# FFXIV KR Data Injector

파이널판타지14 글로벌 클라이언트에 한국어 텍스트, 폰트 및 이미지 리소스를 적용하는 도구입니다. [FFXIV KR Data Extractor](https://github.com/dambyul/ffxiv-kr-data-extractor)에서 배포한 데이터를 사용하며, 한국 서버 클라이언트를 별도로 설치할 필요는 없습니다.

> [!CAUTION]
> - 본 프로그램의 사용으로 인해 발생하는 모든 문제에 대한 책임은 **사용자 본인**에게 있습니다.

## 주요 기능

- **동적 해시 매핑**: 파일 해시를 로컬 저장소에 매핑하여 주입 대상을 찾습니다.
- **EXD 데이터 병합**: 원본 EXD 데이터를 보존하며 CSV의 변경 사항을 선택적으로 주입합니다.
- **텍스처 패키징**: 폰트와 텍스처를 128바이트 블록 정렬 및 표준 비압축 방식으로 패키징합니다.
- **한국어 이미지 적용**: 다운로드한 리소스 패키지의 매칭 정보를 기준으로 글로벌 이미지 리소스를 대응하는 한국어 리소스에 연결합니다. 내장 로더를 통해 모든 글로벌 언어에 적용하며, 매칭 정보가 없는 리소스는 글로벌 원본을 사용합니다.
- **리소스 캐시**: 텍스트·이미지 공통 버전과 별도 폰트 버전을 확인하고, 최신 이미지가 저장돼 있으면 재다운로드하지 않습니다.
- **RSV 검증 알림**: 미해석된 RSV 데이터가 포함된 적용범위 항목에 경고를 표시합니다.
- **주입 필터링**: 외부 프로그램과의 충돌 방지를 위해 특정 파일과 행을 주입 대상에서 제외합니다.
- **설정 외부화**: S3/CloudFront 배포 경로 등의 설정을 `Secrets.cs`로 관리합니다.


## 실행 방법

### 요구 사항

- **OS**: Windows 10 이상
- **대상**: FFXIV 글로벌 클라이언트
- **빌드 환경**: .NET 10 SDK (소스코드 직접 빌드 시)
- **이미지 저장 공간**: 현재 패키지 기준 약 5.33GB 및 다운로드 ZIP 공간

### 환경 설정 (빌드하는 경우)

- `FFXIVInjector.Core/Secrets.Example.cs`를 `FFXIVInjector.Core/Secrets.cs`로 복사하고 배포 URL을 설정합니다.
- `build.ps1`을 실행하여 Windows x64 단일 실행 파일을 생성합니다.
- 이미지 로더 DLL은 실행 파일에 내장되어 별도로 배포할 필요가 없습니다.

### 사용 절차

게임 파일과 로더를 변경하려면 실행 파일을 우클릭하여 **관리자 권한으로 실행**하세요. 일반 권한으로 실행하면 시작 시 안내 모달을 표시합니다.

- **리소스 갱신**: 실행 시 텍스트와 폰트 버전을 확인하고 필요한 데이터를 내려받습니다. 이미지는 적용범위에서 선택한 뒤 적용할 때 확인합니다.
- **적용범위 선택**: 텍스트·폰트 프리셋과 **한국어 이미지 리소스**를 선택합니다. 이미지 항목은 기본 미선택이며, 텍스트의 선택 언어와 독립적으로 모든 글로벌 언어에 적용됩니다.
- **패치 적용**: 게임을 종료한 뒤 적용합니다. 텍스트·폰트는 원본 백업 후 SqPack에 주입하고, 이미지는 `dinput8.dll` 로더를 설치해 로컬 TEX 파일을 연결합니다.
- **이미지 적용 해제**: 이미지 항목의 체크를 해제하고 적용하면 로더 DLL과 설정을 제거합니다. 다운로드한 이미지 캐시는 유지합니다.
- **데이터 복원**: 복원하기에서 백업을 선택하여 텍스트·폰트를 복구합니다. 복원이 성공하면 이미지 리소스 삭제 모달을 표시하며, **예**를 선택한 경우에만 로더를 제거합니다. **아니요** 또는 창 닫기는 이미지 적용을 유지합니다.

텍스트·폰트는 체크 해제 후 적용해도 원본으로 복구되지 않으므로 백업 복원을 사용하세요. 다른 프로그램의 `dinput8.dll`은 덮어쓰지 않습니다. 확인된 기존 개발용 이미지 로더는 백업 후 자동 교체합니다.

### 리소스 및 버전 관리

| 항목 | 배포 파일 | 버전 기준 |
| --- | --- | --- |
| 텍스트 | `rawexd.zip` | `version.txt` |
| 한국어 이미지 | `resources.zip` | 텍스트와 같은 `version.txt` |
| 폰트 | `font.zip` | `font-version.txt` |
| 적용범위·이미지 배포 정보 | `data.json` | 현재 배포 버전 |

S3 루트의 최신 `resources.zip` 하나를 사용하고, 호환성·해시 정보는 `data.json`의 `imageResources`에서 읽습니다. Staging은 기존 `dev-version.txt`·`dev-font-version.txt`를 사용합니다.

이미지 최신 버전이 저장돼 있으면 작은 버전 파일만 확인합니다. 텍스트 버전이 변경돼도 이미지 ZIP 해시가 같으면 캐시를 재사용하며, 손상된 파일은 다시 다운로드합니다. 글로벌 클라이언트 버전과 실행 파일 해시가 패키지의 지원 대상과 일치해야 합니다.

현재 이미지 패키지는 최초 다운로드 약 337MB, 압축 해제 후 약 5.33GB입니다. 캐시는 `%APPDATA%/FFXIVInjector/image-packages`에 저장합니다. 용량은 이후 리소스 업데이트에 따라 달라질 수 있습니다.
